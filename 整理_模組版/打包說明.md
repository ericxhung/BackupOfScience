# 打包成 exe 說明

這個程式現在**兩種方式都能用**：
- 一般執行：`python main.py`（跟以前一樣）
- 打包版：雙擊 `ScienceFairTool.exe`（不用安裝 Python）

## 打包步驟

1. 先確定這台電腦已經能正常執行 `python main.py`（套件都裝好了）。
   不確定的話，可以執行 `pip install -r requirements.txt`。
2. 雙擊 `build_exe.bat`。
3. 完成後，到 `dist\ScienceFairTool\` 資料夾。
4. **要給別人或搬到別台電腦：複製「整個 ScienceFairTool 資料夾」**，不是只複製 exe。
   exe 旁邊的 `_internal` 資料夾是它的零件，少了就打不開。

如果想自己下指令，就是 `build_exe.bat` 裡面那一段 `python -m PyInstaller ...`。

## 版本注意

- 你的 Python 是 3.15，PyInstaller 要 **6.21.0 以上**才支援（我查到最新版是 6.22.3）。
  `build_exe.bat` 會自動更新，可以用 `pyinstaller --version` 確認。
- 如果打包時有「某某套件找不到」的錯誤，多半是那個套件在這台電腦還沒安裝。

## 設定檔放哪裡？

| 執行方式 | 設定檔位置 |
|---|---|
| 一般執行（python main.py） | 目前所在的資料夾（跟以前一樣） |
| 打包版 | **exe 所在的資料夾** |

設定檔包含：`setting.json`、`range_setting.json`、`view_setting.json`、`theme_setting.json`、
`gemini_setting.json`、`view_cache.pkl`。

⚠ 打包版會在 exe 旁邊寫檔案，所以不要把資料夾放在需要系統管理員權限的地方（例如 `C:\Program Files`）。
想沿用舊設定，把舊的 json 檔複製到 exe 旁邊即可。

## 出錯時

- 打包版沒有黑色命令列視窗。程式裡發生錯誤時，會跳出視窗，並把詳細內容寫進 exe 旁邊的 `error_log.txt`。
  把這個檔案內容貼給 Claude 就能查原因。
- 如果一開就消失，改用命令列開啟看錯誤：在資料夾打開 PowerShell，執行 `.\ScienceFairTool.exe`。
  （或把 `build_exe.bat` 裡的 `--windowed` 暫時改成 `--console`，重新打包，就會看到黑色視窗與錯誤訊息。）

## 打包版的限制

- **新增模式要重新打包。** 打包後 `modes` 裡的檔案已經被包進程式裡，之後新增的模式檔案不會自動出現。
  開發時建議用 `python main.py` 測試，確定好了再打包。
- 打包後檔案很大（因為包含 pandas、matplotlib、plotly 等），資料夾約數百 MB 是正常的。
- 防毒軟體有時會誤報自己打包的 exe；用「資料夾版」（現在的做法）比「單一 exe 版」誤報少、啟動也比較快。
- 每次改了程式，要重新執行 `build_exe.bat` 才會更新 exe。
