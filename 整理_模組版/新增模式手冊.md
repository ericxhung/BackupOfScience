# 新增模式手冊

「模式」就是主頁上的一個按鈕（現在有：數據列印、數據整理、檢視），按下去會進入一整組畫面。
這份手冊教你怎麼新增一個模式，而且**不用改任何現有的檔案**。

---

## 1. 資料夾長什麼樣子

```
整理_模組版/
├─ main.py              ← 執行這個。視窗外殼、主題、介面大小、主頁
├─ services.py          ← 所有模式共用的「服務」（讀 Excel、解析日期、取值範圍視窗…）
├─ core.py              ← 共用的取值邏輯（算 Rx、取值範圍、色票、設定檔）。沒有任何視窗
├─ charts.py            ← 畫圖（matplotlib、Plotly）
├─ dialogs.py           ← 共用小視窗與元件（進度視窗、取值範圍視窗、打勾清單）
├─ ai_chat.py           ← AI（Gemini／OpenAI 格式）與 Markdown 顯示
├─ 新增模式手冊.md       ← 就是這份
└─ modes/               ← 每個模式一個檔案
   ├─ base.py           ← 所有模式的「父類別」，不用改
   ├─ __init__.py       ← 自動找出 modes 裡所有模式，不用改
   ├─ print_mode.py     ← 數據列印
   ├─ organize_mode.py  ← 數據整理
   ├─ view_mode.py      ← 檢視
   └─ _template_mode.py ← 範本（底線開頭，不會被載入）
```

一句話記住：**modes 裡面放「各模式自己的東西」，外面放「大家共用的東西」。**

---

## 2. 五步驟新增一個模式

1. 把 `modes/_template_mode.py` **複製一份**，改檔名，例如 `modes/report_mode.py`。
   - 檔名只用英文、數字、底線，**不要用 `_` 開頭**（底線開頭的檔案會被忽略）。
2. 打開新檔案，把類別名稱 `HelloMode` 改成你的名字，例如 `ReportMode`。
3. 改兩個設定：
   - `title = "📑 報表"`：主頁按鈕上的文字，可以放 emoji。
   - `order = 40`：排序，數字小的在前面（目前 10 列印、20 整理、30 檢視）。
4. 在 `start()` 裡面畫出你的第一個畫面（範本有完整示範）。
5. 重新執行 `main.py`，主頁就會自動多一個按鈕。

就這樣。不用改 `main.py`，也不用登記，因為 `modes/__init__.py` 會自動掃描。

---

## 3. 一個模式的基本結構

```python
from modes.base import Mode

class ReportMode(Mode):
  title = "📑 報表"
  order = 40

  def __init__(self, app):
    super().__init__(app)      # 一定要有這行
    self.some_state = []       # 這個模式自己的資料放這裡

  def start(self):             # 主頁按下按鈕會來到這裡
    self.app.clear_container() # 清空畫面
    ...                        # 接著用 ttk 元件畫畫面
```

- `self.app` 就是主視窗，**所有共用服務都從它拿**。
- `start()` 是唯一一定要寫的函式。其他函式（按鈕按下去要做的事）你想寫幾個都可以。
- 模式之間是獨立的：每個模式的狀態只放在自己的類別裡（`self.xxx`），不要直接去改別的模式。

---

## 4. 可以用的共用服務（`self.app.xxx`）

| 寫法 | 用途 |
|---|---|
| `self.app.clear_container()` | 清空目前畫面（換頁前先呼叫） |
| `self.app.container` | 放畫面的容器，元件的 parent 用它 |
| `self.app.show_main_home()` | 回到主頁（「返回主選單」按鈕用） |
| `self.app.px(n)` | 把像素依縮放換算（寫死寬高時用，避免高解析度螢幕太小） |
| `self.app.center_dialog(top, w, h)` | 把一個 `Toplevel` 視窗置中在主視窗上 |
| `self.app.load_infos(paths)` | 讀取一批 Excel 的資訊（有進度視窗、可取消、有快取），回傳字典 |
| `self.app.date_text_of(info)` | 從檔名或資料夾名解析日期（YYYY-MM-DD），解析不到回傳空字串 |
| `self.app.parse_date_from_string(text)` | 從一段文字解析日期 |
| `self.app.request_manual_date(檔名, 資料夾名)` | 跳出視窗請使用者手動輸入日期 |
| `self.app.open_range_dialog(paths)` | 開「取值範圍設定」視窗 |
| `self.app.range_settings` | 目前每個工作表的取值範圍設定 |
| `self.app.info_cache` | 檔案資訊快取 |

樣式名稱（`style=` 可用）：`H2.TLabel`（標題）、`Hint.TLabel`（灰色提示）、`Accent.TButton`（醒目按鈕）、`Title.TLabel`。

顏色請用色票，這樣切換「淺色／科技深色」才會一起變：

```python
from core import PAL
PAL["fg"]      # 文字色
PAL["card"]    # 卡片／清單底色
PAL["accent"]  # 強調色
PAL["warn"]    # 警告紅
```

## 5. 常見需求怎麼做

**讀 Excel 取值（Rx、A0）**

```python
from core import get_values, range_key

infos = self.app.load_infos(paths)          # {路徑: info}；使用者按取消會回傳 None
if infos is None:
  return
for path, info in infos.items():
  for sheet in info["sheets"]:
    if sheet["kind"] == "data":
      key = range_key(path, sheet["name"])
      v = get_values(sheet, self.app.range_settings.get(key))
      print(sheet["name"], v["rx"], v["a0"])
```

**跳出對話框 / 選檔案**（`parent` 要給 `self.app`）

```python
from tkinter import filedialog, messagebox
messagebox.showinfo("標題", "內容", parent=self.app)
path = filedialog.askopenfilename(parent=self.app)
```

**用打勾清單、進度視窗**

```python
from dialogs import CheckList, ProgressWindow
```

**畫圖**：`from charts import draw_chart, build_plotly_html`（用法可以參考 `modes/view_mode.py` 的 `draw`）。

**問 AI**：`from ai_chat import gemini_stream, openai_stream, render_markdown`（參考 `ai_chat.py` 的 `AIMixin`）。

**回主頁按鈕**：`ttk.Button(frame, text="返回主選單", command=self.app.show_main_home)`

## 6. 兩個模式都要用的程式，放哪裡？

先問自己：這段程式「有沒有碰到視窗元件」？

| 這段程式… | 放這裡 |
|---|---|
| 只做計算、讀檔、整理資料（不用 tkinter） | `core.py` |
| 是一個可以重複用的視窗或元件（例如打勾清單） | `dialogs.py` |
| 是「主視窗」才有的功能（例如置中、讀檔進度、日期解析） | `services.py`（寫成 `SharedServices` 的方法，用 `self.app.xxx` 呼叫） |
| 畫圖相關 | `charts.py` |
| AI 相關 | `ai_chat.py` |
| 只有一個模式用 | 留在那個模式的檔案裡，不要拉出來 |

做法：把函式剪下，貼到共用檔案，然後在用到的模式檔案最上面加：

```python
from core import 你的函式名
```

**原則：共用檔案不可以反過來 import `modes` 裡的東西**（否則會「循環 import」而打不開）。

## 7. 出錯時怎麼辦

- **主頁出現紅字「⚠ 模式 xxx 載入失敗」**：那個模式的檔案有錯，其他模式不受影響。紅字後面就是錯誤原因（例如 `SyntaxError`＝打字錯誤、`ImportError`＝import 寫錯）。
- **模式沒有出現在主頁**：檢查 ①檔名有沒有用 `_` 開頭 ②類別有沒有繼承 `Mode` ③檔案是不是放在 `modes` 資料夾。
- **按了按鈕沒反應或跳出錯誤**：通常是 `start()` 裡面寫錯。從命令列（PowerShell）執行 `python main.py`，錯誤訊息會印在那裡。
- **打不開、一開就錯**：多半是共用檔案（`core.py` 等）改壞了。把最近改的地方還原即可。

---

## 8. 刪除或停用一個模式

- **停用**：把檔名改成 `_` 開頭（例如 `_report_mode.py`），主頁就不會出現，內容還在。
- **刪除**：直接刪掉那個檔案即可。
- 不要刪 `base.py` 和 `__init__.py`。

---

## 9. 提醒

1. 每個模式的設定檔如果要存檔，請用**自己的檔名**（例如 `report_setting.json`），不要跟別人撞名。
2. 模式的類別名稱不要重複（兩個叫 `ReportMode` 的類別會互相覆蓋）。
3. 用 `tk.StringVar`、`tk.BooleanVar` 時，寫成 `tk.StringVar(master=self.app, ...)`，比較不會出問題。
4. 改任何東西前，先複製整個資料夾當備份。
